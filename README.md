# Doações RS - Frontend

Este é o frontend do projeto **Doações RS**, uma plataforma para facilitar a conexão entre doadores e pessoas/entidades necessitadas no Rio Grande do Sul.

## Objetivo

O projeto visa criar um ambiente amigável e eficiente para cadastro, busca e gerenciamento de doações, promovendo solidariedade e facilitando o acesso a recursos essenciais em situações de emergência ou vulnerabilidade social.

## Tecnologias Utilizadas

- **JavaScript/TypeScript**
- **React** (presumido pela estrutura e dependências do projeto)
- **Node.js** (gerenciamento de pacotes e scripts)
- **CSS/HTML** (interface)

## Estrutura do Projeto

- `src/` — Código-fonte da aplicação frontend
- `public/` — Arquivos públicos e estáticos (ex: index.html, imagens)
- `.github/` — Configurações e workflows do GitHub Actions
- `package.json` & `package-lock.json` — Gerenciamento de dependências e scripts

## Como rodar localmente

1. **Clone o repositório:**
   ```sh
   git clone https://github.com/doacoes-rs/doacoesrs-fe.git
   cd doacoesrs-fe
   ```

2. **Instale as dependências:**
   ```sh
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```sh
   npm start
   ```

4. Acesse `http://localhost:3000` no seu navegador.

## Scripts Disponíveis

- `npm start` — Roda a aplicação em modo desenvolvimento.
- `npm run build` — Gera uma versão otimizada para produção.
- `npm test` — Executa os testes automatizados (caso configurados).
